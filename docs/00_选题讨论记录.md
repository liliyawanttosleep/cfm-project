## 课程要求（Data Mining Final Project）

- 1–2 人一组；期末每组做 30 分钟 presentation。
- **Final report 截止：Dec 16, 11:59pm**；约 5 页，建议使用正式技术论文格式：Introduction / Related Work / Methods / Experiments / Conclusion / References。
- report 中**必须写明每个成员的个人贡献**。
- 鼓励与研究方向相关，并与 state-of-the-art 比较。
- 如果使用通用数据集，必须应用并分析以下方法：
  1. 一种或多种**线性分类**方法
  2. 一种或多种**决策树或 SVM**方法
  3. 一种或多种**聚类**方法（无监督）
  4. 一些**降维**方法

## 选题结论

**方向：Flow Matching 与 Diffusion 生成模型（以统计视角做对比研究）**

选择理由：
1. **前沿**：Diffusion 和 Flow Matching 是当前图像、视频、蛋白质生成的主流方法（Stable Diffusion 3 / Flux 基于 Rectified Flow）。
2. **统计背景契合**：核心是 score matching、Langevin 采样、SDE/ODE、最优传输、变分推断。
3. **可上手**：2D 数据与 MNIST 上用单 GPU 几小时就能训完；我们之前已跑通 torchcfm 的 2D 例子和 CIFAR-10 生成（FID ≈ 12）。
4. **满足课程硬性要求**：课程方法用于“评估生成质量”，用法自然，不需要生硬地拼凑：
   - 线性分类与树/SVM → TSTR（Train on Synthetic, Test on Real）
   - 降维 → 用 PCA / t-SNE / UMAP 比较真实与生成分布
   - 聚类 → 用 k-means / GMM 衡量模式覆盖率（mode coverage）

## 讨论过的备选方案（未采用）

- **VAE / GAN / Diffusion / FM 四模型横向对比**：范围太宽。最终聚焦 FM 与 Diffusion，VAE/GAN 只在 Related Work 中提及。
- **表格数据合成**（CTGAN / TabDDPM / TabSyn + SDV 库）：统计味道更浓，但网络训练部分学得少，可作为后续研究方向。
