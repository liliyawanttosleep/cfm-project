# 01 项目计划

## 暂定题目

**Flow Matching vs. Diffusion: A Statistical Comparison of Simulation-Free Generative Models**
（中文：基于统计视角的 Flow Matching 与扩散模型对比研究）

## 研究问题（report 围绕这 4 个问题展开）

| # | 问题 | 对应实验 |
|---|---|---|
| Q1 | 在同一个网络、同样的训练预算下，Flow Matching（I-CFM / OT-CFM / Rectified Flow）与 Diffusion（DDPM / DDIM）的生成质量差多少？ | E1, E2 |
| Q2 | 采样步数（NFE）与生成质量之间是什么关系？为什么 FM 的轨迹更“直”、少步时更好？ | E1, E2 |
| Q3 | 生成数据在统计意义上与真实数据有多接近？能否替代真实数据训练分类器？ | E3 |
| Q4 | 生成模型是否覆盖了所有模式（类别）？是否存在 mode collapse 或类别不均衡？ | E1, E3 |

## 统一实验设定（保证公平对比）

- **同一网络**：2D 实验用 MLP（3×64 或 3×256）；图像实验用 `torchcfm.models.unet.UNetModelWrapper`，FM 和 DDPM 共用这一结构。
- **同样的训练预算**：相同的 batch size、训练步数、优化器（Adam，lr 2e-4）和 EMA 设置。
- **随机种子**：每组设定跑 3 个种子，报告均值 ± 标准差（这是统计系的加分点）。
- **DDPM 自己实现**：在 torchcfm 的 UNet 上写约 50 行 DDPM 训练与采样代码，不直接用 diffusers 的另一套网络，以保证对比时只有算法这一个变量。diffusers 只作为实现参考。

## 实验设计

### E1：2D toy 数据（理解算法 + 做图）
- 数据：8 gaussians → moons、N(0, I) → moons、swiss roll、checkerboard。
- 方法：I-CFM、OT-CFM、Rectified Flow（含 1 次 reflow）、DDPM、DDIM；统计基线为 GMM 和 KDE。
- 指标：W2 距离（POT 库）、MMD（RBF 核）、测试集 NLL（GMM/KDE 可直接计算；CNF 通过 torchdyn 的 trace 估计）、轨迹直线度（straightness）。
- 图：样本散点图、向量场、ODE 轨迹、不同 t 时刻的分布演化。

### E2：MNIST（主实验；Fashion-MNIST 作为第二数据集）
- 方法：DDPM（1000 步）、DDIM（10/20/50/100 步）、I-CFM、OT-CFM（Euler 1/2/5/10/20/50/100 步，以及 dopri5 自适应）。
- 主指标：FID（`clean-fid` 或 `torchmetrics`）。MNIST 上 FID 的特征提取器是 Inception，需在 report 中说明这一局限，可补充使用在 MNIST 上训练的 LeNet 特征计算 “MNIST-FID”。
- 关键图：**FID vs NFE 曲线**（FM 与 Diffusion 画在同一张图）。
- 加分：conditional MNIST + classifier-free guidance（repo 中已有 `examples/images/conditional_mnist.ipynb`），扫描 guidance scale w。

### E3：用课程方法评估生成数据（满足课程硬性要求）
每个生成模型产生 60k 张图，用一个预训练的 MNIST 分类器给生成图打伪标签（或直接使用条件模型的类别）。

| 课程要求 | 方法 | 用途 |
|---|---|---|
| 线性分类 | Logistic Regression（含 L2）、LDA | **TSTR**：在生成数据上训练、在真实测试集上测试，与 TRTR（真实训练、真实测试）对比 |
| 树 / SVM | Random Forest、RBF-SVM | 同上；另做 **real-vs-fake 判别器**，判别准确率越接近 50% 说明分布越接近 |
| 降维 | PCA（解释方差）、t-SNE、UMAP | 把真实和生成样本投到同一空间可视化；比较 PCA 前 k 个主成分的分布 |
| 聚类 | k-means（k=10）、GMM | 在生成样本上聚类，与（伪）标签计算 ARI / NMI；统计各簇占比，用 **χ² 检验**检验类别是否均匀（检查 mode collapse） |

### E4（可选扩展，二选一）
- **CIFAR-10**：利用已有的 OT-CFM 结果（FID ≈ 12），画 NFE vs FID 曲线，并与论文报告值比较（state-of-the-art 对比）。
- **Reflow / 一步生成**：在 MNIST 上做 2-Rectified Flow 或 MeanFlow，比较 1 步生成的质量。
