## 开源代码库

| 库 | 地址 | 用途 |
|---|---|---|
| **torchcfm** | https://github.com/atong01/conditional-flow-matching （本地：`../conditional-flow-matching-main/`） | 主力库：CFM / OT-CFM / RF loss、UNet、MNIST/CIFAR 例子 |
| flow_matching（Meta） | https://github.com/facebookresearch/flow_matching | 配合 01 号论文，代码规范，可作参考 |

| DDPM 官方代码 | https://github.com/hojonathanho/diffusion | 原始超参数 |
| score_sde_pytorch | https://github.com/yang-song/score_sde_pytorch | SDE 框架的官方实现 |
| rectified-flow | https://github.com/gnobitab/RectifiedFlow | RF 官方实现（含 2D notebook） |
| torchdyn / torchdiffeq | https://github.com/DiffEqML/torchdyn ，https://github.com/rtqichen/torchdiffeq | ODE 求解（dopri5、Euler） |
| POT | https://pythonot.github.io/ | W2 距离、minibatch OT |
| clean-fid | https://github.com/GaParmar/clean-fid | FID 计算 |
| scikit-learn / umap-learn | https://scikit-learn.org ，https://umap-learn.readthedocs.io | 课程方法（E3） |
