Flow Matching vs. Diffusion · 10

[Wentao · ~2 min] The only free choice in conditional flow matching is how to pair noise points with data points. Independent pairing, used by I-CFM and rectified flow: straight lines from different pairs cross, and where they cross the network can only learn the average direction, so the resulting flow curves. Lipman's original version uses a Gaussian path toward x_1 and behaves much like I-CFM. OT-CFM solves an optimal-transport problem inside each minibatch so that the total squared distance of the pairs is minimal. Optimal pairs rarely cross, so the learned flow is nearly straight. Straightness S measures this: if S = 0, one Euler step is exact. Rectified flow can straighten further with reflow — retraining on the model's own noise–sample pairs. Keep the minibatch OT in mind; it comes back when we discuss high dimensions.
