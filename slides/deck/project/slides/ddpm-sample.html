Sampling, and why ε is a score

Ancestral sampling: t = T, …, 1

xₜ₋₁ = (1/√αₜ) ( xₜ − βₜ/√(1 − ᾱₜ) · εθ(xₜ, t) ) + σ̃ₜ z

σ̃ₜ² = (1 − ᾱₜ₋₁)/(1 − ᾱₜ) · βₜ, z ~ N(0, I)

Stochastic, and needs T = 1000 network calls per sample.

Noise prediction = score estimation

∇ₓ log pₜ(x) ≈ − εθ(x, t) / √(1 − ᾱₜ)

E[x₀ | xₜ] = ( xₜ + (1 − ᾱₜ) ∇ log pₜ(xₜ) ) / √ᾱₜ

Tweedie’s formula: the denoiser is a posterior mean; this is denoising score matching.
