Diffusion (DDPM + DDIM)

Train

x₀ ~ data, t ~ U{1..T}, ε ~ N(0, I)

xₜ = √ᾱₜ x₀ + √(1 − ᾱₜ) ε

step on ‖ εθ(xₜ, t) − ε ‖²

Sample

x ~ N(0, I)

for N chosen steps t → s:

x̂₀ = (x − √(1−ᾱₜ) εθ) / √ᾱₜ

x = √ᾱₛ x̂₀ + √(1−ᾱₛ) εθ

Flow matching (I-CFM / OT-CFM)

Train

x₁ ~ data, x₀ ~ N(0, I), t ~ U(0, 1)

[OT-CFM: re-pair x₀, x₁ by OT]

xₜ = (1 − t) x₀ + t x₁

step on ‖ vθ(xₜ, t) − (x₁ − x₀) ‖²

Sample

x ~ N(0, I)

for k = 0 … N−1:

x = x + vθ(x, k/N) / N

【B 讲，约 1 分钟】 左右对照：两种方法的训练都是“随机取数据点、噪声、时间 → 构造中间点 → 做一次 MSE 回归”，区别只在中间点怎么构造、回归的目标是什么（ε 还是 x_1 − x_0）。 采样都是从高斯噪声出发、迭代 N 步，每步调用一次网络，所以 NFE = N。 我们自己的实现就是这样写的：两边用同一个网络，只换目标和采样器——这是后面“公平比较”的基础。
