Full expansion: L_CFM = L_FM + C

1. Expand the square, with v = vθ(t, xₜ)

‖v − (x₁ − x₀)‖² = ‖v‖² − 2⟨v, x₁ − x₀⟩ + ‖x₁ − x₀‖²

2. v depends only on (t, xₜ), so use the tower rule

E⟨v, x₁ − x₀⟩ = E⟨v, E[x₁ − x₀ │ xₜ]⟩ = E⟨v, uₜ(xₜ)⟩

3. Do the same for L_FM = E‖v − uₜ(xₜ)‖², and subtract

L_CFM(θ) = L_FM(θ) + E‖x₁ − x₀‖² − E‖uₜ(xₜ)‖²

4. The constant is a conditional variance, free of θ

C = E[ tr Var(x₁ − x₀ │ xₜ) ] ≥ 0

Same gradient

∇θ L_CFM = ∇θ L_FM, so regressing on single pairs trains the marginal field.

The floor is not zero

At (0.5, 0.1): 0.69 × (3.8 − 1.32)² + 0.31 × (−4.2 − 1.32)² = 13.69, the floor from slide 13.

Do not compare losses across pairings

C depends on the coupling. A lower loss under OT pairs can mean fewer conflicts, not a better model, as on slides 18 and 27.
