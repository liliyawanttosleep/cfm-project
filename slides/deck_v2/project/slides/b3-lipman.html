pₜ(x│x₁) = N( t x₁, σₜ² I ), σₜ = 1 − (1 − σ_min) t

uₜ(x│x₁) = ( x₁ − (1 − σ_min) x ) / ( 1 − (1 − σ_min) t )

With σ_min = 0 it is our target

Write xₜ = t x₁ + (1 − t) x₀ with x₀ ~ N(0, I). Then:

(x₁ − xₜ) / (1 − t) = x₁ − x₀

So on a Gaussian source, the two regressions coincide.
