Schrödinger bridge CFM

Entropic pairs, and a noisy bridge

(x₀, x₁) ~ π, the Sinkhorn OT plan with regularization 2σ²

pₜ(x│x₀, x₁) = N( t x₁ + (1 − t) x₀, t(1 − t) σ² I )

The target has one extra term

uₜ(x│x₀, x₁) = (1 − 2t) / (2t(1 − t)) · (x − μₜ) + (x₁ − x₀)

μₜ = t x₁ + (1 − t) x₀. The new term is the rate at which the bridge width changes: it spreads points out until t = 0.5, then pulls them back.

Limit

As σ → 0, the plan tends to exact OT and the bridge width to 0, so SB-CFM reduces to OT-CFM.
