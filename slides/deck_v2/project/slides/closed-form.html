Step 4. Check it: a velocity in closed form

Paths from integrating the formula, with no network.

Setup: x₀ ~ N(0, 1), and x₁ = ±a with probability ½ each.

1 · Rewrite the target on a line

x₁ − x₀ = (x₁ − xₜ) / (1 − t)

uₜ(x) = ( E[x₁ │ xₜ = x] − x ) / (1 − t)

2 · Apply Bayes, with xₜ │ x₁ ~ N( t x₁, (1 − t)² )

E[x₁ │ xₜ = x] = a · tanh( a t x / (1 − t)² )

3 · Result

uₜ(x) = ( a · tanh( a t x / (1 − t)² ) − x ) / (1 − t)

a = 2, t = 0.5, x = 0.1: (0.76 − 0.1) / 0.5 = 1.32, as on the last slide.

Numerical check: 200,000 N(0, 1) points integrated with this formula all reach ±2, about half to each.

[Wentao · ~1.5 min] Step four is a sanity check. For our small example, the posterior mean has a closed form, so we can test the claim directly, without any neural network. First, rewrite the target. On a line, x₁ minus x₀ equals x₁ minus x_t, divided by one minus t. Taking the conditional expectation gives the velocity in terms of one quantity: the expected data point given where we are now. This is a denoiser, and it will come back when we talk about diffusion. Second, apply Bayes’ rule. Given x₁, x_t is Gaussian with mean t x₁ and variance one minus t squared. With two data points, the posterior mean is a tanh. Third, put them together. This is the exact marginal velocity. Plug in our point, a equals 2, t equals 0.5 and x equals 0.1, and we get 1.32, the same number as on the last slide. Now the test: we integrated this formula from 200,000 Gaussian points. All of them end up at plus or minus two, about half on each side. Nothing was trained. So the velocity defined by the posterior mean really does transport noise to data. Also notice that the individual lines on the previous slides cross, but these marginal paths do not. A point at a given location and time has only one velocity. This becomes important when we discuss why paths bend. In real data we cannot compute this posterior mean, so we need a network to learn it. That is the next step.
