Flow Matching vs. Diffusion · 4 · Adapted from torchcfm, examples/images/mnist_example.ipynb

[Wentao · ~1.5 min] This is essentially the whole training code, adapted from the torchcfm MNIST example. Take a batch of real data and the same number of noise samples. Pick a random time, take the point on the straight line between each noise sample and its data point, and read off the velocity of that line. Then fit the network to that velocity by least squares. There is no likelihood, no ODE solve during training, and no discriminator. This looks too simple, and it raises three questions, which organize the rest of the talk. First, why this target? Given the input, x₁ minus x₀ is still random, because many pairs pass through the same point. Second, why does the trained network actually generate data? Third, why does changing how we pair noise with data let sampling take fewer steps? We will answer the first two with the theory, and the third with 2D experiments. We then connect the method to diffusion and scale it up to images. Kaiming will start with the basic setup.
