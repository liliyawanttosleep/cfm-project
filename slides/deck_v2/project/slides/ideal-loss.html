The ideal loss, and why we cannot compute it

L_FM(θ) = E t, x~pₜ ‖ vθ(x, t) − uₜ(x) ‖²

In words

At a random time and a point on the path, make the network’s velocity match the true one.

Why it helps generation

At L_FM = 0, vθ = uₜ along the path, so integrating the network from noise gives data.

In code

We cannot write it: nothing in the data gives us uₜ(x).

Flow Matching vs. Diffusion · 8

[Kaiming · ~1 min] If we knew the right velocity field, training would be simple regression: at a random time and a random point on the path, make the network’s velocity match the true velocity. This is the flow matching loss. If it reaches zero, the network equals the true field along the path, and by the continuity equation, integrating it from noise gives data. But we cannot write this loss in code, for two reasons. First, the target is unknown: we only have samples from the data distribution, so we know neither p_t nor u_t. Second, the target is not even defined until we choose a path. The figure shows three different paths with the same two endpoints, and each would give a different velocity field. So we need a path that we choose ourselves and that gives a target we can compute. Wentao will now show how to build one, starting from a single pair of points.
