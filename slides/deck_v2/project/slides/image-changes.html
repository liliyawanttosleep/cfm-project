[Kaiming · ~1.2 min] So far everything lived in two dimensions. Now we move to images, and the first question is what has to change. The table shows the honest answer. The data go from 2 numbers to 784 pixels. The MLP becomes a U-Net with about a million weights, and training takes half an hour per model instead of a few minutes. But look at the orange card. These are the same lines as on slide 4, and on MNIST the library call does exactly this. That is not luck. The derivation in Part II never used the dimension. One thing must change: the metric. Empirical W2 converges like n to the minus one over d, which is hopeless at 784 dimensions. So we use FID, and Wentao will explain it on slide 26. We carry three predictions from 2D. I-CFM in one step should land on the data mean. OT-CFM should need fewer steps. DDIM should be weakest at very few steps. Let us see which survive.
