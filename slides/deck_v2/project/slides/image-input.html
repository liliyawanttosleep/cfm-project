Part V · From 2D to MNIST

Step 2. What the network sees

Input and output have the same shape

Input: the 28 × 28 image xₜ and the time t. Output: a 28 × 28 velocity, one number per pixel. That is why a U-Net fits: it maps an image to an image, and t enters every residual block through a time embedding.

In code, model(t, xt) has the shape of x1 − x0: 1 × 28 × 28.

The same formula, for 784 coordinates

uₜ(x) = E[ x₁ − x₀ │ xₜ = x ]

Each target is mostly noise, so the loss cannot reach 0. The network learns the average.

Example: a corner pixel

It equals −1 in all 60,000 training images, so x₁ is known. The posterior mean has one term, and the path is exactly straight:

uₜ(x) = (−1 − x) / (1 − t)

Example: the center pixel

Its mean is 0.02 and its standard deviation 0.89: stroke or background. At t = 0 the network can only aim at the mean. Later, the nearby pixels reveal the digit, and its aim changes. That change bends the path.

The last column is the regression target, x-one minus x-zero. It is mostly noise, with a faint digit. So no network can match it exactly, and the loss will never reach zero, as on slide 13. Input and output have the same shape, so a U-Net is natural, and time enters each residual block. The target is still the posterior mean, now in 784 coordinates. Two pixels make this concrete. The corner pixel is minus 1 in every training image, so the posterior is certain, and the velocity is just minus 1 minus x, over one minus t. That path is straight. The center pixel is either stroke or background. At the start the network can only aim at the mean. Later the neighbors reveal the digit, the aim changes, and the path bends.
