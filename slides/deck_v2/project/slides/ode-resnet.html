Part I · Generation as transport

A ResNet with many small steps is an ODE

Example: N(0, 1) to the two points ±2. Arrows show uₜ(x).

xₖ₊₁ = xₖ + (1/K) · u(xₖ, tₖ) (residual block)

dx/dt = uₜ(x), x(0) ~ p₀ (K → ∞)

In words

Each block adds a small correction to its input. In the limit, uₜ(x) is the velocity of a particle at position x and time t.

Why it helps generation

To sample, start from noise and integrate to t = 1. The cost is the number of network calls, NFE.

In code

for k in range(K):

x = x + model(k / K, x) / K

Flow Matching vs. Diffusion · 6

[Kaiming · ~1.3 min] You all know residual blocks: the output is the input plus a correction. If we use many small blocks with step size one over K, and give the network the time as an input, this is exactly a forward Euler step. As K goes to infinity we get an ordinary differential equation: dx/dt equals u of x at time t. So u is a velocity field: it tells a particle at position x and time t where to move. The figure shows a simple example, from a standard Gaussian to two points at plus and minus two. The arrows are the velocity, and the orange curves are exact solutions. The navy line uses Euler with four steps, which means four network calls. This gives us the sampling algorithm: draw noise and integrate to time one. The number of network calls is NFE, the number of function evaluations. It is the cost we use on the x-axis for the rest of the talk. A straight path can be followed with few steps; a curved path needs more.
