Step 2. Velocity, noise, score: one posterior mean

1 · Condition the path on xₜ = x (straight path)

x = t x̂₁ + (1 − t) ε̂

with x̂₁ = E[x₁ │ xₜ = x] and ε̂ = E[x₀ │ xₜ = x]. One linear equation: know one, know the other.

2 · The velocity is their difference

uₜ(x) = E[x₁ − x₀ │ xₜ = x] = x̂₁ − ε̂ = (x − ε̂) / t

3 · The score averages Gaussian scores

Given x₁, xₜ ~ N( t x₁, (1 − t)² I ), so

∇ log pₜ(x │ x₁) = −(x − t x₁) / (1 − t)² = −x₀ / (1 − t)

Average over x₁ given xₜ = x (Fisher’s identity):

sₜ(x) = ∇ log pₜ(x) = −ε̂ / (1 − t)

[Kaiming · ~1.2 min] Both networks learn a posterior mean. How are they related? Take the path equation and condition on x_t equals x. That gives one linear equation linking the expected data and the expected noise, so if you know one, you know the other. The velocity is their difference. Substituting gives x minus epsilon-hat, over t. So a noise network gives a velocity, with no retraining. For the score, use Fisher’s identity: the score of a mixture is the posterior average of the component scores. Each component is Gaussian, with score minus x₀ over one minus t. Averaging gives minus epsilon-hat over one minus t. Check on our point from Part II: noise minus 0.56, velocity 1.32 as on slide 12, and score 1.12, which the two-Gaussian mixture confirms directly. Steps one and two always hold. The score step needs x₀ given x₁ to be Gaussian, so it fails for a mixture source and for OT pairs. All three have the same optimum, but a network’s errors do not convert evenly. That matters next.
