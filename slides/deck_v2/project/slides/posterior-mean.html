Step 3. The velocity is a posterior mean

uₜ(x) = E[ x₁ − x₀ │ xₜ = x ]

= ∫ uₜ(x │ z) · pₜ(x │ z) q(z) / pₜ(x) dz

In words

Average the velocities of all lines through (t, x), weighted by the posterior probability of each pair (Bayes’ rule).

[Wentao · ~2 min] This is the most important slide of the talk. Step three: what is the velocity of the mixture? Stand at one point in space and time. Several lines pass through it, and each has its own direction. But a single velocity field can have only one value at that point. The theorem says that value is the average of the line velocities, weighted by how probable each line is, given that we observed a line at this point. That is a posterior mean: the expected value of x₁ minus x₀ given x_t equals x. Let’s compute it for the example at t equals 0.5 and x equals 0.1. Because the data has only two points, exactly two lines pass through here. One goes to plus two: it must start at minus 1.8, so its velocity is plus 3.8. The other goes to minus two: it must start at 2.2, so its velocity is minus 4.2. Which is more likely? Both data points have probability one half, so the weight depends on the noise density: minus 1.8 is more likely than 2.2 under a standard Gaussian. The posterior weights are 0.69 and 0.31. The average is 0.69 times 3.8, plus 0.31 times minus 4.2, which is 1.32. That is the marginal velocity at this point. Why does this generate data? Each single line, with its velocity, satisfies the continuity equation. The equation is linear in the density and flux, so we can integrate it over q(z). The mixture flux is exactly p_t times this average velocity, so the pair p_t and u_t satisfies the continuity equation. By Kaiming’s test, integrating u_t from noise gives data. So the first problem is solved in principle, because we can now write down the correct field. In general, though, the integral is intractable. On the next slide we can compute it, because the example is so simple.
