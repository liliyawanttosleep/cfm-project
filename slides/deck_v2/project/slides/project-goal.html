Flow Matching vs. Diffusion · 2

[Wentao · ~1.2 min] Here is the project in one sentence. We want to explain how flow matching turns generation into a regression problem, and then measure how it trades sample quality against sampling cost compared with diffusion. That gives three goals. First, explain: why does a simple least-squares regression give a correct generative model? This is most of today’s talk. Second, compare: with the same network and the same training budget, how does quality change with the number of network calls per sample? Third, evaluate: is the generated data useful? We use the methods from this course to check whether it can train classifiers and whether it covers every class. We do this at three scales, so we can see what survives as the dimension grows: 2D toy data, MNIST with 784 dimensions and CIFAR-10 with 3,072.
